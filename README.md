# 功耗统计（Android）

实时记录手机整机功耗，并统计：

- **每分钟平均功耗**（近 60 分钟，柱状图 + 列表）
- **每小时平均功耗**（近 24 小时，按本地整点）
- **开机至今平均功耗**（附覆盖率、总耗电 mWh）
- **亮屏平均功耗** / 息屏平均功耗（开机至今）
- 上一分钟、最近 60 分钟、本小时平均

## 原理

- 前台服务每秒（息屏时每 5 秒）读取 `BatteryManager.BATTERY_PROPERTY_CURRENT_NOW` 电流与电池广播中的电压，功率 = 电流 × 电压。
- 相邻采样用梯形积分得到能量，按墙钟分钟切分累加，每分钟写入 SQLite（保留 30 天）。
- 息屏后 CPU 休眠会导致采样空档：空档期间优先用电量计 `CHARGE_COUNTER` 的电荷差估算能量，不可用时取两端较小的功率保守估算。
- 亮灭屏广播会立即触发一次采样，保证亮屏/息屏时间段划分准确。
- 充电/插电时电池电流不代表设备功耗，这段时间不计入平均值（单独记录时长）。
- 开机广播自动启动服务，因此「开机至今」基本覆盖整个开机时长；界面会显示覆盖率。

## 注意

- 各厂商电流单位/符号不统一：应用放电时取绝对值，并自动识别 µA / mA；识别错误时可在「设置」中手动指定。
- 部分系统（MIUI、ColorOS 等）会杀后台，请在「设置 → 关闭电池优化」并允许自启动。
- 监测服务本身也会消耗少量电量。

## 构建

需要 JDK 17 与 Android SDK（compileSdk 34）：

```bash
./gradlew assembleDebug
# 产物：app/build/outputs/apk/debug/app-debug.apk
```

推送到 GitHub 后，Actions 会自动构建并上传 APK（在对应运行的 Artifacts 中下载）。
